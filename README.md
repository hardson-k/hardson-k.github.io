## 本地开发与部署

```powershell
# 简历与作品集通过 hash / 锚点路由，需以 http 方式预览
git add -A; git commit -m "更新站点内容"; git push origin master
```

推送到 `master` 后 GitHub Pages 约 1–2 分钟生效。新增图件后执行 `python scripts/gen_thumbs.py` 重新生成缩略图。
