# uploads / 云文档库

本目录用于存放对外分享的云文档（备考资料、备份文件等）。

## 使用须知

- 本仓库为 **公开仓库**，放入本目录的任何文件都会被公开索引，任何知道链接的人都能下载。
- **禁止**放入：身份证号、账号密码、令牌密钥、合同原件、体检报告等涉密或个人敏感材料。
- 单文件建议 ≤ 25 MB（GitHub 硬性上限 100 MB，超了推不上去）；整个仓库建议 ≤ 1 GB。

## 上传方式

在项目根目录执行：

```powershell
.\scripts\upload-cloud.ps1 -Path "D:\要上传的文件.pdf"
```

脚本会自动复制到本目录并提交推送。上传完成后，打开站点的云文档页面即可看到。

## 展示页面

`html/cloudfiles.html` —— 该页面通过 GitHub 开放接口实时读取本目录内容，无需后端。
